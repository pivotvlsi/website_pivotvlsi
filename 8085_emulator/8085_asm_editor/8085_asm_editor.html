🗄️ 8085 Register Specification
A (Accumulator): 8-bit Primary Arithmetic & Logic register
B, C: 8-bit General Purpose / 16-bit BC Pair
D, E: 8-bit General Purpose / 16-bit DE Pair
H, L: 8-bit General Purpose / 16-bit HL Pointer
M [HL]: Memory operand at address addressed by HL
SP: 16-bit Stack Pointer (pointing to stack top)
PC: 16-bit Program Counter (execution sequence)
Flags (PSW): Sign (S), Zero (Z), Aux Carry (AC), Parity (P), Carry (CY)
