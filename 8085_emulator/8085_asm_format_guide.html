📌 Overview & Supported Assembly File Formats

The PIVOT VLSI Intel 8085 Microprocessor Emulator supports loading assembly files (.asm or .txt) directly into its 64KB RAM address space (0000H to FFFFH). You can specify target memory addresses using two primary conventions: the standard ORG (Origin) directive or Address Prefix syntax.

Format Method Syntax Example Description
ORG Directive (Recommended) ORG 0800H or ORG 2000H Sets the target memory load address for all instructions and data definitions that follow. Multiple ORGs are supported.
Address Prefix Format 0800H: MVI A, 05H or 0800 MVI A, 05H Standard disassembler / listing notation where each line starts with its 4-digit hexadecimal address.
Define Byte (DB) DB 10H, 20H, 30H Defines raw 8-bit data bytes directly into consecutive memory locations starting at the current address.
Define Word (DW) DW 1234H, 0800H Stores 16-bit words into memory following 8085 Little-Endian convention (low-order byte first, then high-order byte).
Labels & Comments LOOP: DCR C • ; comment Target addresses for jumps/calls are automatically calculated and resolved; comments start with ; or //.

⚡ Method 1: Using the ORG Directive (Industry Standard)

The ORG (Origin) directive sets the assembly base address. Both hexadecimal (0800H, 0x0800) and decimal (2048) values are recognized. You can place your executable program instructions at one memory segment and data tables or scratchpad buffers at another memory segment in the same file. 

; ==============================================================================
; PIVOT VLSI 8085 Example: Separate Program and Data Sections
; ==============================================================================

; --- 1. Program Code Section (Target Address: 0800H) ---
ORG 0800H
START:  LXI H, 0900H      ; Point HL register pair to data array at 0900H
        MOV A, M          ; Load first byte (25H) into Accumulator
        INX H             ; Increment memory pointer to 0901H
        ADD M             ; Add second byte (18H) to Accumulator
        STA 0950H         ; Store total sum at memory location 0950H
        HLT               ; Halt CPU execution

; --- 2. Data Memory Section (Target Address: 0900H) ---
ORG 0900H
DATA1:  DB  25H           ; First input operand stored at 0900H
DATA2:  DB  18H           ; Second input operand stored at 0901H
💡 Automatic PC Initialization: When an .asm file is imported, the emulator automatically initializes the Program Counter (PC) to the first ORG address (or first instruction address), updates the Disassembly Table, and scrolls directly to that instruction!

📋 Method 2: Address Prefix Format (Disassembly / Listing Style)

If you have existing code exported from a disassembler, EPROM programmer, or laboratory manual with line addresses, you can load it directly without modifying each line: 

0800H: MVI A, 05H        ; Load 05H into Accumulator
0802H: MVI B, 03H        ; Load 03H into Register B
0804H: ADD B            ; Accumulator = A + B (08H)
0805H: STA 2000H        ; Store result at 2000H
0808H: HLT               ; Halt

Note: The trailing colon is optional (e.g. 0800H MVI A, 05H or 0800: MVI A, 05H are also accepted).

🚀 Step-by-Step: How to Load & Run in the Emulator

  1. Open the Emulator: Navigate to 8085_emulator.html.
  2. Import Your File: In the left Instruction Memory pane, click 📁 Import Assembly (.asm/.txt) and select your file.
  3. Validate Instructions: Click ✔️ Validate Instructions to inspect opcodes, operand types, and syntax.
  4. Observe PC & Disassembly: Notice that the Program Counter (PC) updates to your specified origin (e.g. 0x0800), and the instruction disassembly table scrolls to and highlights that instruction row.
  5. Step or Run: Click ▶ STEP for single-instruction execution or ⚡ AUTO RUN for continuous clock execution.
