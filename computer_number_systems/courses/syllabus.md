# Computer Number Systems

Welcome to the Computer Number Systems course! This syllabus outlines the topics covered, video resources, and hands-on codelabs.

## 📚 Course Syllabus

1. **Introduction to Number Systems**
   - Decimal, Binary, Octal, and Hexadecimal Systems
   - Understanding Radix 

2. **Number Base Conversions**
   - Converting from Decimal to Binary/Octal/Hexadecimal
   - Converting from Binary/Octal/Hexadecimal to Decimal
   - Inter-conversions between Binary, Octal, and Hexadecimal

3. **Signed Numbers Representation**
   - Sign-Magnitude Representation
   - 1's Complement and 2's Complement Representation

4. **Complements and Subtraction**
   - 1's and 2's Complements

5. **Binary Arithmetic**
   - Binary Addition 
   - Binary Subtraction via complement

6. **Positional and Non-positional Number Systems**
   - Positional Number Systems
   - Non-positional Number Systems

7. **Gray code**
   - Gray code generation
   - Gray code conversion
